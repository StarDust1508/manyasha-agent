# Установка Маняши на Windows 11

## Требования

- Windows 11 x64;
- Node.js 22 или новее;
- Git;
- `uv`;
- PowerShell 5.1 или новее.

Установщик останавливается, если обязательной команды нет или версия Node.js ниже 22. Он не изменяет системную политику исполнения PowerShell.

## Установка из ZIP

1. Скачайте ZIP и соседний файл `.sha256`.
2. Проверьте SHA-256 командой `Get-FileHash -Algorithm SHA256 .\Manyasha-0.2.0-windows.zip`.
3. Распакуйте архив.
4. Из корня пакета выполните:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install-windows.ps1
```

По умолчанию приложение устанавливается в `%LOCALAPPDATA%\Manyasha\app`, а профиль — в `%LOCALAPPDATA%\Manyasha`. Каталог `bin` добавляется в пользовательский `PATH`; новый терминал увидит команду `manyasha`.

## Первый запуск

```powershell
manyasha gui
```

Откройте адрес, напечатанный командой. История разговоров хранится в локальном профиле. Для доступа, выданного сайтом, выполните команду подключения устройства, показанную в личном кабинете.

## Удаление

Остановите Маняшу, затем удалите `%LOCALAPPDATA%\Manyasha\app`. Профиль и историю удаляйте отдельно только если они больше не нужны.
