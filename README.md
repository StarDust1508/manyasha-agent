# Маняша · устанавливаемый агент — product-boundary prototype

Это изолированный прототип отдельного продукта. Он не читает и не изменяет `~/.hermes`, OpenCode, пользовательские ключи, память или каналы.

Проверяемый срез:

1. терминальный запуск;
2. локальный профиль;
3. явные разрешения чтения и записи;
4. сравнение двух файлов и настоящий сохранённый результат;
5. тот же результат в GUI;
6. смена маршрута `managed` / `byok` / `local` без потери сессии.

Запуск:

```bash
npm test
npm run demo
npm run gui
```

Кандидат основы и закреплённая ревизия находятся в `upstream.lock.json`. Движок ещё не адаптирован; это не готовый установщик macOS/Windows и не подтверждение мессенджеров, фоновых задач или модельного доступа.
