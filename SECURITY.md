# Безопасность

Не публикуйте в issue ключи API, личные документы, полные журналы сессий и содержимое пользовательского профиля.

Официальный репозиторий — `StarDust1508/manyasha-agent`. Приватный канал сообщения об уязвимости ещё не опубликован владельцем; обычный issue не подходит для ключей, документов и полных журналов.

Проверяемые свойства текущего среза:

- отдельные профиль, HOME и рабочая папка;
- закреплённый commit Hermes;
- ключ модели не записывается в конфигурацию поставки;
- файловый прототип отклоняет выход за рабочую папку и символические ссылки;
- терминальные инструменты отключены.

Ограничение: `HERMES_WRITE_SAFE_ROOT` не является полной OS-песочницей чтения.
